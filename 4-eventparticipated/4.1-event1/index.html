Event 1 - Enterprise Cloud Architectures and Industry Application

Enterprise Cloud Architectures and Industry Application

  • Event Name: Enterprise Cloud Architectures and Industry Application
  • Date & Time: July 4, 2026
  • Location: 26th Floor, Bitexco Financial Tower, 2 Hai Trieu Street, Sai Gon Ward, Ho Chi Minh City, Vietnam
  • Role: Attendee

Event objectives

  • Understand how enterprises design and operate systems on AWS.
  • Learn about current Cloud/AI hiring trends and the skills expected from junior cloud engineers.
  • Exchange knowledge directly with industry experts and experience the community spirit of AWS First Cloud AI Journey.

Speakers

  • Nguyen Tran Minh Duy – Industry Liaison Officer, Swinburne Vietnam.
  • Nguyen Gia Hung – Head of Solution Architecture, AWS Vietnam.
  • Khang Nguyen – Solution Architect, Cloud Kinetics.
  • Vinh Banh – Senior Data Engineer, Renova Cloud.

Event highlights

1. Education, enterprise, and community connection

The opening session explained how university education can connect more closely with real industry requirements. The Study Tour gave students an opportunity to visit the AWS Vietnam office, observe a professional working environment, and learn from practitioners. Integrating AWS Academy into cloud-computing courses also helps students establish the foundations needed for practical projects.

I was particularly impressed by the Pay it Forward culture of the AWS First Cloud AI Journey community, where experienced participants return to share knowledge and guide newer students.

2. The Cloud/AI recruitment market

The session emphasized that an intern should not only know several isolated AWS services. Foundations such as Linux, Networking, Docker, and Kubernetes are increasingly important because engineers need to understand how a complete cloud system operates.

The speaker also discussed the Hidden Job Market. Many opportunities originate from referrals and professional communities rather than public job boards, so technical competence and networking should be developed together.

3. Enterprise cloud architecture in practice

Enterprises in banking, finance, insurance, and e-commerce are moving important workloads to the cloud. This is more complex than transferring an application to virtual servers: the architecture must address security, high availability, scalability, legacy migration, reliability, and operating cost as a connected set of requirements.

4. Problem-solving mindset and career development

When asking for technical support, engineers should describe the context, state their assumptions, list what has already been verified, and ask a focused question. This makes troubleshooting and teamwork more efficient. The speakers also stressed collaboration between engineering, business, and marketing, as well as the importance of consistent learning and practice.

Personal application to Startups Blogs

As the member responsible for the React frontend and Hugo workshop documentation, I connected the event lessons with the Startups Blogs project:

  • I viewed Cognito, API Gateway, EC2, RDS PostgreSQL, S3, and CloudFront as one system instead of separate AWS services.
  • I paid more attention to networking, security boundaries, availability, and scalability when documenting the deployment architecture.
  • I learned to record assumptions and completed checks before investigating frontend-to-API or API-to-database connection errors.
  • I understood that clear technical documentation is part of delivering an enterprise solution, not merely a record of configuration steps.

Key takeaways

  • Strengthen Linux, Networking, Docker, Kubernetes, and Infrastructure as Code fundamentals.
  • Evaluate security, scalability, availability, reliability, and cost together when designing cloud systems.
  • Analyze the context and state assumptions before requesting technical support.
  • Develop professional connections alongside technical ability.
  • Maintain consistent hands-on learning through real projects.

Event experience

Attending the event in person gave me a more practical view than learning only from documentation or online courses. The presentations connected education, recruitment, enterprise architecture, problem solving, and career development. They also helped me understand that a stable React application depends on the quality of the entire cloud architecture behind it.

Overall, the event helped me approach the Startups Blogs project as a scalable cloud system rather than only an application that functions correctly. It also strengthened my motivation to participate in technical communities and continue learning from practical projects.
