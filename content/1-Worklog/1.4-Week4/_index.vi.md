### Mục tiêu tuần 4:

- Hiểu về kiến trúc không máy chủ (Serverless Architecture).
- Tìm hiểu dịch vụ AWS Lambda và Amazon API Gateway.
- Nắm cơ chế giám sát và ghi log bằng Amazon CloudWatch.
- Xây dựng một quy trình công việc (workflow) serverless đơn giản.

### Kết quả đạt được tuần 4:

- Nắm vững tư duy thiết kế kiến trúc Serverless Architecture.
- Tạo và thực thi thành công các hàm AWS Lambda.
- Cấu hình chuẩn xác execution role, bộ nhớ và timeout cho Lambda.
- Hiểu rõ cách API Gateway đóng vai trò làm cổng giao tiếp API cho xử lý backend.
- Kết nối thành công API Gateway tới AWS Lambda.
- Làm chủ công cụ giám sát Amazon CloudWatch.
- Thành thạo việc tra cứu log để khắc phục sự cố hệ thống.
- Xây dựng thành công một workflow API serverless hoàn chỉnh.
